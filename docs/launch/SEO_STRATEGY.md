# Search and content strategy

Position: open-source, self-hosted Agile project management for engineering teams (MIT owner-approved). Focus on practical install/workflow answers rather than unsupported Jira parity or broad “best tool” claims.

The isolated static site implements one H1, descriptive title/description, semantic sections, accessible navigation, a labeled workflow diagram and responsive light/dark CSS. No tracking, third-party fonts or invented ratings are included. Default builds are noindex; build with the approved SITE_URL to emit canonical URL, OG image, SoftwareApplication JSON-LD, sitemap and robots. No hostname is assumed or deployed. Avoid indexing private app routes; the separate marketing site needs no authentication exception.

| Search intent | Useful page/article | Evidence needed |
| --- | --- | --- |
| self-hosted project management | Install guide + operations responsibilities | Clean Docker install evidence |
| Docker project management software | Compose tutorial | Exact commit, secret configuration, migrations, health/login |
| self-hosted Kanban board | Real board tour | Authentic synthetic-data screenshot |
| open source sprint planning | Sprint workflow tutorial | Actual iteration/capacity behavior |
| open source Jira alternative | Workflow-based evaluation comparison | Feature/limitation matrix, no parity claim |
| Azure DevOps Boards alternative | Mapping backlog/iteration concepts | Verified terminology and supported workflows |

Weeks 1–2: publish install and configuration guides after validation. Weeks 3–4: publish the real backlog→sprint walkthrough and backup tutorial. Month 2: publish a migration/evaluation checklist and transparent architecture/security notes. Month 3: improve pages based on actual search questions and installation reports; do not create duplicate keyword pages.

After authorized deployment, verify TLS, redirects, canonical origin and sitemap; inspect social previews; submit sitemap through owner-controlled search-console accounts. Measure search impressions/clicks and installation-guide visits only with approved privacy-respecting aggregate analytics. No search ranking or adoption guarantees. Recheck broken links and outdated commands with every release.
