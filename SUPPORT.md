# Support

For installation problems, read [getting started](docs/getting-started.md) and [troubleshooting](docs/troubleshooting.md), then open a bug report with the exact commit, environment, command and sanitized output. For workflow ideas, use a feature request. Search existing issues first.

[Issues](https://github.com/guptabibek/rabbitflow/issues) are the currently linked public support path. GitHub Discussions and private security reporting require owner enablement; no chat server, hosted support service or response SLA is advertised. Never post secrets, private projects or database dumps. Use [SECURITY.md](SECURITY.md) for vulnerabilities.
