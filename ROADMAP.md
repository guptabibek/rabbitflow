# Roadmap

This is a proposed sequence, not a delivery commitment.

1. **Release foundations:** owner-approved license, working clean deployment, private disclosure channel, green CI, database/search verification and backup/restore drill.
2. **Evaluation experience:** authentic screenshots, short walkthrough, reproducible synthetic workspace and isolated demo operations.
3. **Contributor experience:** verified newcomer installation, scoped first issues, documented API and release process.
4. **Operational confidence:** cross-browser/accessibility journeys, dependency-loss/restart testing, performance measurements on declared infrastructure.
5. **Community priorities:** rank workflow improvements using reproducible reports and feedback from real installations.

[90-day execution plan](docs/launch/GROWTH_ROADMAP.md) · [Release gates](docs/launch/RELEASE_CHECKLIST.md). Feedback should describe a concrete team workflow and the result it needs.
